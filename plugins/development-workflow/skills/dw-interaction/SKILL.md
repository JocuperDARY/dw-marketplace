# 人机协作与沟通

本 skill 属于 [development-workflow](../development-workflow/SKILL.md)。当用户、执行者和观察者对目标、权限、进度或完成的理解不一致时，用它恢复共同理解并继续工作。简单事项保持直接对话。长任务复用现有任务记录。

## 对齐用户要得到的结果

把用户原问题和追加要求落实到交付物、使用入口、验收证据及停止条件。逐项回答子问题和括号里的追问，再按需要给解释、改稿或实际操作。用户说「没看懂」时，找出缺失的条件、术语、传递对象或决策依据，用同一个具体例子连起来。用户纠正方向时，应用到受影响的工作和现行记录，其余仍有效的要求继续执行。

接续时从用户指定的权威来源、当前工件和真实运行状态重建下一步。把当前事实、历史快照、待验证解释、用户决定和暂用假设分开。发现旧资料与现场冲突时，按各自能证明的范围核对，已做完的工作直接接上。

## 只问会改变行动的决定

先完成能靠现有证据判断的部分。仍需用户决定时，说明已知事实、受影响动作、可行选项及后果，再给有依据的建议。只问目前真正阻塞的决定，同时推进独立工作。一旦已有答复或新证据使下一步明确，落实决定并撤回过时问题。

按问题上下文解释自由回答和「按建议」「不限」等简短回复。工具收件回执和沉默都不提供决定。按用户指定的对象、条件和范围应用授权。常规可逆工作在已有授权内连续推进。范围改变、外部传输、不可逆动作或实际限额耗尽时，核对当前授权及平台约束。[查看决定、恢复与运行边界](references/decisions-and-continuity.md)。

## 持续推进并反馈重要变化

按真实依赖安排工作，说明旁支和相邻组件如何影响主交付；旁支未证实影响主线时，可按既有验收条件收口。局部失败时先保护已有结果，确认哪些后续步骤依赖它。完成独立工作，并在授权和实际资源允许时修复可恢复的问题。助手自增的门槛妨碍用户目标时，查明来源并在适用范围内修正。保留明确生效的预算、停止条件和科学判据。

有多个执行方时，用一个当前工作入口识别谁调度、谁执行、谁观察和谁验收。根据用户要求和实际状态变化汇报进度、故障或待决事项。用户询问状态时给实际分母、现行障碍和下一可观察结果，然后继续当下工作。接续、交接和消息同步保留用户已为当前会话选择的运行设置。

## 用实际结果收口

沿用户使用的入口验收交付物和动作。分别说明已完成、部分成功、失败、未开始和无法核验的事项。给出证据、覆盖分母、关键比较条件和影响结论的假设。遇到暂停或换手，说明执行、数据回收、监控和资源各处于什么状态，留下可恢复结果与首个动作。[查看解释、交付验证与对话复盘](references/explanations-and-evidence.md)。

按实际需要深读既有规范：[文字与图示](../dw-writing/SKILL.md)、[方案与技术取舍](../dw-planning/SKILL.md)、[验证与复核](../dw-verification/SKILL.md)、[执行方与资源](../dw-collaboration/SKILL.md)、[交接与恢复](../dw-handoff/SKILL.md)。
